## 🚀 Getting Started

### Prerequisites
- Node.js installed

### Installation

```bash
# Clone the repository
git clone https://github.com/mk6084518-design/my-portfolio.git
cd my-portfolio

# Install dependencies
npm install
```

### Run Locally

```bash
npm run dev
```

App will run at `http://localhost:5173` (or your configured port).
